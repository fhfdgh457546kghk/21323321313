# Notion Effort для Notion на ПК (Windows, Notion.exe)

Запускает панель расширения внутри Notion.exe. Скрипты берутся из папки расширения (корень репозитория, уровень выше) как есть, поэтому держите эту папку внутри репозитория или задайте путь в `NOTION_EFFORT_EXT`. Нужен Node.js 22+.

## Запуск

Двойной клик по `Notion Effort.cmd`. Скрипт перезапускает Notion с отладочным каналом (DevTools pipe) и через CDP (`Page.addScriptToEvaluateOnNewDocument`) подключает те же `unlock.js`, `inject.js`, `models.js`, `composer.js` ко всем страницам Notion, включая новые вкладки. Окно консоли нужно держать открытым: если его закрыть, панель пропадёт.

- `Notion Effort diag.cmd` — сохраняет `diag.json` в этой папке и копирует его в буфер обмена.
- `Notion Effort stop.cmd` — останавливает панель. Сам Notion продолжает работать.
- Панель перестала отвечать? Закрой окно консоли и запусти `Notion Effort.cmd` заново.

## Безопасность

Notion запускается с `--remote-debugging-pipe`, а не с портом. Канал — это потоки самого процесса Notion, поэтому подключиться к сессии Notion может только этот скрипт; порт наружу не открывается и запросов от брандмауэра нет. Локальный порт 9310 (меняется через `NOTION_EFFORT_CONTROL`) слушает только `127.0.0.1` и умеет лишь две вещи: отдать диагностику и остановить панель.

Режим `--port` (как было раньше) остался для отладки: он открывает DevTools-порт (`NOTION_EFFORT_PORT`, по умолчанию 9230) для любой программы на этом компьютере. Для повседневной работы он не нужен.

## Хранение настроек

`chrome.storage` заменён прослойкой на `localStorage` страницы (ключи `notionEffortExt:*`), поэтому выбор модели и effort у версии для ПК и у расширения в браузере хранится отдельно.

## Настройки

- `NOTION_EXE` — полный путь к `Notion.exe`. По умолчанию скрипт сам смотрит `%LOCALAPPDATA%\Programs\Notion`, затем пакет MSIX из Store.
- `NOTION_EFFORT_EXT` — папка расширения, если она не уровнем выше этой папки.
- `NOTION_EFFORT_CONTROL` — порт управления панелью, по умолчанию 9310.
- `NOTION_EFFORT_PORT` — порт DevTools, только для режима `--port`.
